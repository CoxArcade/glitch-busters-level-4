# QuestForge / Glitch Busters — Level 4: Keyboard Kingdom

CoxArcade educational debugging adventure for Python Pixel Playground.

## GitHub Pages deployment

1. Create a **new public GitHub repository** named `glitch-busters-level-4`.
2. Upload the **contents inside this ZIP's top-level folder** to the repository root. Make sure `game/main.py` and `.github/workflows/deploy.yml` are preserved.
3. In GitHub, go to **Settings > Pages** and select **GitHub Actions** as the build/deployment source.
4. Open **Actions** and wait for **Build and publish Level 4** to succeed.
5. Play at `https://coxarcade.github.io/glitch-busters-level-4/` if your GitHub username is `coxarcade`.

## Controls

Arrows/WASD: move; Z: attack; E: interact / hack; X: dash; C: bow; B: bomb; H: heal; V: Overdrive; J: journal; R: report; M: music.

Code editor: Enter creates a line; Tab adds four spaces; Ctrl+Enter submits.

## Contents

`game/main.py`: complete Level 4 game. `game/*.ogg`: original Level 3 sound assets carried forward. `.github/workflows/deploy.yml`: pygbag browser build and GitHub Pages publishing.
